# 🎮 Lastdep
Ваша новая игровая зависимость (в хорошем смысле!)  
Простая и оооооочееееень увлекательная игра, созданная чтобы разбавить рутину и подарить несколько секунд чистого наслаждения. (до тех пор, пока не проиграл)  

## ✨ Особенности
⚡ Мгновенный старт — никаких долгих обучений😍👌  
🎨 Красивая пиксель-графика — глаз радуется👁️😀  
🎵 Веселый саундтрек — создаёт позитивный настроение👍😁  
🎯 Интуитивное управление — разберётся даже Игнатий Могила💅💅  

## ⌨️ О Игре
Вы попали в подпольное казино и вам надо крутить бурмалду💵, чтобы выжить!

## 🚀 Быстрый старт
> 😰 Скачиваем Python 3.13+ (с включенным path)😭  
> 🤷‍♂️ Скачиваем git (с включенным path) 😭  
> 🙌 Вводим командники:  
```powershell/bash
git clone https://github.com/ваш-username/lastdep.git

cd lastdep

pip install -r requirements.txt
```
> 🚀 Запускаем:
```powershell/bash
python main.py
```
